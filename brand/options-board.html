Dot: logo options

Five architectures, one dot. Each is tested at 16 / 32 / 64 px on light and dark, in one colour, and as the three live states. Text is outlined (JetBrains Mono, SIL OFL 1.1). Nothing is exported yet.

One accent hue. Amber is reserved for the thinking state, never decoration. Full ramp and tokens: tokens.css, palette-report.txt. Idle on dark is 3.5:1, above the 3:1 graphic floor; light-theme accent is exactly 3.0:1, so on light backgrounds the dot needs size, not thinner strokes.

Options

A - Dot on a ruleSymbol only

Construction. One solid dot resting on a prompt rule: the period at the end of a sentence, the cursor line of a terminal.
Verdict. The purest read of the brief: the mark IS the state indicator. Weakness: no letter, so it is ownable only through repetition and the rule is the only thing separating it from a generic status LED.

Recommendation

D, the letterform with the dot counter, used with a Dot wordmark in JetBrains Mono, and the bare dot lifted out as the product's state indicator.

  • It is the only option where letter and idea are one object: the dot lives in the D, so idle / thinking / waiting happen inside the brand mark.
  • Strongest silhouette of the five and a clean one-colour version (the counter is a true cut-out).
  • The dot alone (A's core) already exists in the UI as the status light, so the mark and the live indicator rhyme without duplicating.
  • Fix before export: a favicon cut with a larger dot (r 7.5) and smaller hole (r 10); the 16 px dot is only about 1.5 px in the current draft.
  • Fallback if the owner wants zero risk at 16 px: C (tile), which is the most robust app icon.
