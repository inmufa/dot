# Dot logo brief

**Brand name:** Dot (Latin only; en/ru/uz UI strings never change the name).
**What:** self-hosted, uncensored, autonomous coding and research agent that runs on the owner's own machine.
**Audience:** one technical owner, plus later self-hosting developers. Seen in a terminal UI, a local web UI, a browser tab, the README.
**Smallest size:** 16 px (favicon, tab). Also a 32-64 px status indicator inside the UI.
**Adjectives:** precise, calm, technical.
**Must NOT look like:** a chatbot mascot or sparkle/AI-glow cliche; a neon hacker/skull "uncensored" trope; a corporate gradient blob.
**Neighbours:** Claude Code, opencode, Aider, Ollama, Cursor. All lean on monochrome marks, wordmarks or a single glyph; none owns a dot.
**Memorable thing:** one dot. It is also the live state indicator: idle (dim), thinking (amber, pulsing), awaiting approval (accent).
**Constraints:** hand-built SVG on a 64 grid with overshoot, text outlined (no live fonts), one-colour version, light and dark, a state-dot version; flat colour, no gradients. Name has no Uzbek letters, so no oʻ/gʻ glyph need.
**Colour:** one accent hue, restrained; amber reserved for "thinking". No brand colour constraint from the owner (unknown, tell me if there is one).
**Approver:** the project owner. Deliverable now: five options and a recommendation; no export until one is picked.
